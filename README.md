# AWA1 — Watches — Bryan Zweiacker

Swiss watch catalogue (Tissot) built with Vue 3, Vite and an Express API, used to practise web animations.

## Requirements

Node.js LTS and npm.

## Getting started

1. Install dependencies: `npm install`
2. Terminal 1: `npm run server` (API at `http://localhost:3001/api/watches`)
3. Terminal 2: `npm run dev` (open the URL shown by Vite)
